# HUD Profiles

Saved **Stationeers UI Ascended** HUD layout documents (the F9 designer's profiles), kept here
for versioning and sharing. Each `.xml` is one self-contained `HudDocument`.

## Use one
Drop the `.xml` into your game's profile folder, then pick it in F9 → Profiles:

```
<Stationeers>/BepInEx/config/StationeersUIMod/HudProfiles/
```

The mod regenerates the shipped **Default** on first run if the folder is empty, so these are
optional extras — the "Glassy" line is the design history behind the current shipped default.

> Note: user-named/custom profiles are never auto-upgraded by the mod (only the shipped
> defaults are), so an older custom profile keeps exactly the layout you saved.
