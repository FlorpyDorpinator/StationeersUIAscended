# 0.9.0 Experimental — Play-Test Checklist & Where Everything Lives

Written for FlorpyDorp's play-test pass. Everything below is already built + deployed to
`BepInEx/scripts` (F6 to load) and the shader bundle is built at
`Dev/UiaEffectsBundle/Build/uia_effects.bundle` (the mod finds it there automatically in dev).

---

## 1. Where the new features live (menu map)

| What | Where | Notes |
|---|---|---|
| **All global effect toggles** | **F9 → "Effects (global) — 0.9.0"** | The master switches for Tier A / B / C + every strength/speed knob |
| **Per-element effect overrides** | **F9 → click any element → "Effects (this element)"** | 9 new rows at the bottom: Pulse, Shine, Iridescence, Dissolve, Frost (+ strengths) |
| **Bulk reset** | Bottom of the F9 Effects (global) section | "Reset ALL per-element effect overrides" — one undo step (Ctrl+Z works) |
| **Profiler window** | **F9 → "Profiler" → Show profiler window** | Or console: `uiaprof on` |
| **Console commands** | The game console | `uiaprof [on\|off\|clear\|save\|ab <effect>]` |
| **Profiler snapshots** | `BepInEx/config/StationeersUIMod/ProfilerSnapshots/` | Markdown files, one per `save`/ab-phase |
| **Raw config** (everything above + frost tint/downsample) | F10 window / `BepInEx/config/…cfg`, section **"11. HUD Effects (0.9.0)"** | FrostTint (#B6BCC2 gray), FrostDownsample live only here |

**Defaults you agreed:** Tier A **ON** · Tier B **ON** (auto-inactive if the bundle is missing) ·
Tier C (frost) **OFF** — you must switch it on to test it.

**What effects apply to:** our drawn panels and lines (boxes, bars, readout frames, polylines).
By design they never touch vanilla icons, the portrait, moodlet icons, or the damage doll
(those are real vanilla objects we borrow — hands off).

## 2. Smoke test (2 minutes)

- [ ] Load a world → **F6** → log shows `0.9.0 Experimental initialized`, no red errors
- [ ] **F9 → Effects (global)** → Tier B header says **"TIER B — shader effects"** — NOT
      "(bundle not loaded — inactive)". *(If inactive: tell Claude — the bundle didn't load.)*
- [ ] HUD looks **identical to 0.8.0** at first glance (defaults are deliberately subtle)
- [ ] **F6 again** (double hot-reload) → still clean: no duplicate HUD, no frozen canvases,
      `uiaprof` still responds

## 3. Tier A — mesh effects

- [ ] **Hairlines fade instead of vanishing:** F9 → Draw a line → set **Line width ≈ 0.2** →
      the line becomes a faint whisper (before 0.9.0 it blinked out below ~0.5). Slide width
      0 ↔ 2 and watch it fade smoothly, never pop.
- [ ] **Edge light on lines:** Effects (global) → drag **"Line edge-light strength"** 0 → 2 →
      drawn lines brighten on the side facing up-left (same light as panel borders). Set back ~0.55.
- [ ] **Pulse:** click an element (e.g. a readout box) → its popup → tick **"Pulse (breathing)"**
      → it breathes gently. Check two pulsing elements are NOT in lockstep (deliberate phase
      offsets). Untick → returns to normal instantly (no stuck tint).
- [ ] Turn **Tier A master OFF** → hairline/edge-light/pulse all stop → back ON.

## 4. Tier B — shader effects (needs the bundle — it's built ✓)

- [ ] **Shine sweep:** within ~9s of loading, a light band slides across panels. Change
      **"Shine period"** to 3s to see it often; **"Shine sweep strength"** 0 = off.
- [ ] **Iridescence:** crank **"Iridescence strength"** to 1.0 → subtle rainbow shimmer on
      panels → set back to ~0.25 (it should be a whisper at default).
- [ ] **Boot dissolve:** take your suit off, put it back on → panels power on behind a bright
      travelling frontier (alongside the classic flicker). Toggle **"Dissolve reveal on
      boot"** off → plain flicker only.
- [ ] **Per-element override:** click the top bar → untick "Shine sweep" just for it → the
      sweep skips the top bar but still runs elsewhere.
- [ ] **Fallback test (important):** quit game → rename `uia_effects.bundle` to `.bak` →
      launch → ONE log warning, Tier B header shows "(bundle not loaded — inactive)", HUD
      is fine in Tier-A-only mode, no errors → rename back.

## 5. Tier C — frosted glass (EXPERIMENTAL, off by default)

- [ ] Be in **Flat or Warp (A)** curvature (F10) — frost deliberately sits out B/C/D
- [ ] Effects (global) → tick **"Enable frosted-glass backdrop"** → panels now blur + darken +
      gray-tint the world behind them
- [ ] ⚠️ **ORIENTATION CHECK (the known risk):** look through a panel at something
      recognizable (a lamp above you) — if the world through the glass is **upside-down**,
      that's the Y-flip case. Tell Claude — it's a one-line runtime flip, not a rebuild.
- [ ] Walk around — the frost updates smoothly (it re-blurs every 2 frames by default;
      "Re-blur every N frames" slider trades smoothness vs cost)
- [ ] **"Frost darkening"** slider works live; tint/downsample are in the cfg (F10)
- [ ] Switch curvature to **B**, then **C**, then **D** → frost cleanly disappears (no
      leftovers, no errors) → back to Flat/A → frost returns
- [ ] Per-element: untick "Frosted glass" on one element → only that one goes back to normal

## 6. The profiler + cost numbers (the point of 0.9.0)

- [ ] `uiaprof on` → the **UIA Profiler** window appears: `Frame.Total`, `Hud.Update.Total`,
      `Hud.Sample/Relayout/Content/Anim`, `Hud.Mesh.*` rows with live ms
- [ ] Idle HUD sanity: `Hud.Mesh.Panel` **Calls/s ≈ 0** when nothing moves (rebuild-storm
      tripwire — if it's high while idle, that's a bug, report it)
- [ ] **`uiaprof ab frost`** → hands off for ~24s → console prints
      `ON x.xxx ms | OFF x.xxx ms → cost +x.xxx ms`. **Write that number down** — it's the
      headline cost of frost on your machine. (Budget hope: ≤ 1.5 ms.)
- [ ] `uiaprof ab shine`, `uiaprof ab tiera` — same drill (expect ~0.0–0.2 ms)
- [ ] `uiaprof save` → a Markdown file appears in
      `BepInEx/config/StationeersUIMod/ProfilerSnapshots/`
- [ ] Effects list for `ab`: `tiera · tierb · tierc/frost · shine · edgelight · irid ·
      chroma · pulse · dissolve`

## 7. Regression sweep (the "nothing broke" pass)

- [ ] Your existing profiles (Glassy 4.0, custom) look **unchanged** with the new toggles off
- [ ] F9 editor still fully works: drag/resize/undo/redo/duplicate/delete, per-element popups
- [ ] Suit death + boot with dissolve + glitch + collapse all enabled — transition looks sane
- [ ] Moodlets, portrait, damage doll all normal (borrowed vanilla objects must be untouched
      by effects — if a moodlet icon ever looks tinted/corrupted, that's a P0, report it)
- [ ] Mode C (world-space curvature): edit a profile while IN mode C — add a box, duplicate an
      element → new elements render correctly (this exercises the latent bug we fixed)
- [ ] MP client smoke test if convenient: join a server → HUD normal, nothing new networked
- [ ] Double-F6 at the very end with everything enabled → clean

## 8. If something's wrong — quick kill-switches

Every layer has an off switch, worst-case first:
1. Per-element: the element popup's Effects rows
2. Per-effect: its slider/toggle in Effects (global)
3. Per-tier: the three master toggles (Tier C → Tier B → Tier A)
4. Nuclear: F10 → Visor HUD off (vanilla HUD returns)

## 9. Known limitations (by design, not bugs)

- Frost only in Flat/Warp curvature (B/C/D deferred)
- Boot dissolve is synchronized across panels (the per-element staggered version is planned)
- Effects don't apply to vanilla `Image` icons or borrowed vanilla objects (deliberate)
- Shader *math* changes need a bundle rebuild (UIA → Build Effects Bundle) then F6; all
  settings/strengths are live without any reload
