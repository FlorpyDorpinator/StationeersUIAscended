# 0.9.0 Settings, Explained — what every knob actually does

Plain-language reference for the F9 → **"Effects (global) — 0.9.0"** section, the per-element
effect rows, and the config-only knobs. Written after the first play-test fix round (2026-07-14),
so this describes the CURRENT behavior.

**The one rule that explains everything:** an effect shows only when THREE switches agree —
the **tier master** is on, the effect's **global strength** is above zero, and the **element's
own checkbox** (in its popup) is ticked. Global sets the look; per-element opts out (or scales).

---

## TIER A — mesh effects (cheap, on by default)

| Setting | What it does | How to see it |
|---|---|---|
| **Enable Tier A** | Master switch for the three effects below | — |
| **Thinnest line (px)** | How thin a drawn line is ALLOWED to get. Below 1px a line renders 1px wide but becomes **transparent in proportion** — so it fades out gracefully instead of blinking out of existence | Draw a line in F9, set its width to 0.2 — it becomes a faint whisper. Raise this floor if hairlines annoy you |
| **Line edge-light strength** | A directional light that brightens edges facing up-left — **both** drawn lines **and every panel border** (since the fix round; before it only touched lines, which is why it "did nothing"). This is the "border is lighter in some places, darker in others" effect | Drag it 0 → 2 and watch the TOP edges of every box catch light while bottom edges stay dim |
| **Pulse speed (Hz)** | How fast a pulsing element breathes (cycles per second) | Only visible on elements that opted in |
| **Pulse depth** | How deep the dim half of the breath goes (0 = imperceptible, 1 = fades to black) | — |

**Pulse is opt-IN per element:** nothing pulses until you tick "Pulse (breathing)" in an
element's popup. That's deliberate — a whole HUD breathing in sync looks broken, not alive.

## TIER B — shader effects (needs `uia_effects.bundle`; on by default when it loads)

| Setting | What it does | How to see it |
|---|---|---|
| **Enable Tier B** | Master for shine/iridescence/dissolve. If the header says "(bundle not loaded — inactive)" none of these can work | — |
| **Shine sweep strength** | Brightness of the light band that slides across panels ("very anime" — set 0 to kill it entirely) | Watch any big panel; band crosses once per period |
| **Shine period (seconds)** | Time between sweeps. The band itself always takes ~1.2 s to cross; this is the WAIT between crossings | Set 3 s while tuning, put back ~9+ s for taste |
| **Iridescence strength** | The soap-bubble rainbow — now confined to panel **rims** (the fix round: it used to paint diagonal rainbow stripes across whole panels). A whisper at 0.25; still subtle at 1.0 by design | Look at panel edges/corners; the hue drifts slowly across the screen |
| **Chromatic aberration** | Colour fringing of the **frosted backdrop** at panel rims — only does anything while **Tier C frost is on** (it needs the blurred world texture to fringe). This is why it seemed wild/confusing before: it's a frost sub-effect, not a stand-alone | Turn frost on, then drag this |
| **Dissolve reveal on boot** | When the suit powers on, panels materialise behind a travelling bright frontier instead of just flickering | Take suit off/on |

## TIER C — frosted glass (EXPERIMENTAL, off by default)

| Setting | What it does | How to see it |
|---|---|---|
| **Enable frosted-glass backdrop** | The showpiece: panels show a **blurred, darkened, gray-tinted** copy of the world behind them, and become near-opaque glass. Works **independently of Tier B** (fix round: it used to silently require Tier B). Flat/Warp curvature only | Toggle it and look through the top bar at terrain |
| **Frost darkening** | How dark the world behind the glass goes (0 = bright glass, 1 = black) | Live slider |
| **Re-blur every N frames** | The blur refreshes every N frames. 1 = smoothest + priciest; 8 = cheapest, world "lags" slightly behind the glass | `uiaprof ab frost` at different N |
| *(cfg only)* **FrostDownsample** | Blur resolution: 4 = quarter res (default, cheap), 2 = sharper + pricier | F10 / cfg file |
| *(cfg only)* **FrostTint** | The glass colour, `#RRGGBB`. Default `#B6BCC2` — the cool gray you asked for | F10 / cfg file |

## Per-element rows (any element's popup → "Effects (this element)")

Older rows (collapse/glitch/warp) unchanged. New in 0.9.0 — each is *that element's* say:

- **Pulse (breathing)** + strength — opt-in, see Tier A above
- **Shine sweep** + strength — untick to exempt this element from the sweep
- **Iridescent edge** + strength — same, for the rainbow rim
- **Dissolve reveal** — whether this element joins the boot dissolve
- **Frosted glass** + strength — whether this element's panel becomes frost glass, and how strongly (0.5 = half-frost: translucent glass)

The strengths multiply the globals — global sets the ceiling, the element scales under it.

## Profiler section

- **Show profiler window** — the live cost table. Read: `Frame.Total` = whole game frame;
  `Hud.Update.Total` = our entire HUD (currently ~0.26 ms — the budget is 1.0);
  `Hud.Mesh.*` **Calls/s should be ~0 when idle** (if not, something is rebuilding meshes
  every frame — report it); `Fx.Blur.Dispatch` = frost's CPU cost.
- **Snapshot** — writes a Markdown table to `BepInEx/config/StationeersUIMod/ProfilerSnapshots/`
  *(fix round: used to land in a doubled `StationeersUIMod/StationeersUIMod/` folder)*.
- Console: `uiaprof ab <effect>` = the real cost of one effect (ON minus OFF, ms/frame).
  Effects: `tiera · tierb · tierc/frost · shine · edgelight · irid · chroma · pulse · dissolve`.

## Round-2 additions (the concept-art knobs, 2026-07-14)

Every effect now has its **own checkbox** under its tier master (your ask #4). New controls:

| Setting | What it does |
|---|---|
| **Ripple (irregular shimmer)** + frequency | Light/dark variation ALONG borders and lines — organic, non-repeating (layered waves), so frames look "randomly glowy" like the concept art. Frequency = how often it alternates |
| **Border fade** | Unlit sections of a frame DISSOLVE: 0 = solid outline everywhere, 1 = only the light-catching parts of the border exist. THE concept-art border look |
| **Soft edge (px)** | Panel fills fade out over N px instead of ending crisply — adjacent boxes melt into each other |
| **Glow halo** + width | A luminous halo around frames, tinted by each element's own accent — an amber warning chip bleeds amber onto the glass around it (your POWER LOW observation). True element-to-element lighting (bloom) is a future item; this is the cheap 90% |
| **Box → Border: top/right/bottom/left** | Per-side border kill switches on Box elements — turn any of the 4 sides invisible; it melts away smoothly around the corners |
| Per-element: **Border fade / Soft edge / Glow (-1 = global)** | The same trio per element, sheen-style |

**Concept-art starting recipe:** Border fade ~0.5 · Ripple ~0.5 @ freq 2–3 · Soft edge ~10 ·
Glow ~0.3 @ 24px · Edge light ~0.7 · frost ON with darkening ~0.5. Tune from there.

Also fixed: **frost no longer replaces shine/iridescence** — Tier B effects now layer on top of
frosted panels.

## Round-3 additions (2026-07-15): glow both ways, HUD bloom, radial glass

### Glow, matured (F9 → Effects (global) → Glow halo)
- **glow outward strength** (0–2) — the halo outside the frame (the old slider, brighter now).
- **glow inward strength** (0–2) — NEW: the same light bleeding INTO the glass (the concept
  art's "lines glow into and out of the box"). Independent of outward.
- **glow width** (6–160px) — shared by both directions; the inward depth self-caps in
  shallow boxes and miters cleanly into corners.
- **glow diffuseness (haze)** (0–1) — 0 hugs the frame as a tight rim glow; 1 spreads a wide
  soft haze (dimmer at the frame, wraps more of the perimeter, immune to ripple streaks).
- **ripple** now goes to **2.5** — above ~1.4 it overdrives: dark troughs go fully dark (the
  line visibly breaks up) and bright crests overshoot into the specular and the glow.
- Per-element popup rows: **Glow out / Glow in** (−1 = follow global).

### HUD BLOOM — elements light each other (F9 → Effects (global), own block; default OFF)
The real thing: any bright HUD pixel (borders, text, chips, halos) bleeds light onto its
neighbours. Routes the HUD through a render texture in every curvature mode (Curved (world)
excepted — use Curved (RT)).
- **bloom strength** (0–3) — how much extracted light is added back.
- **bright threshold** (0–1.5) — how bright a pixel must be to bloom. Lower = more glows.
- **soft knee** (0–1) — how gently the cutoff ramps.
- **blur steps** (1–5) — the reach: each step DOUBLES it (it's a resolution pyramid, so
  integers only — that's what spread is for).
- **spread** (0.5–3) — the CONTINUOUS width fine-adjust between the step doublings.
- **fine-detail bloom** (checkbox, on) — thin borders + drawn lines survive into the bloom
  (half-res extraction; off = softer/cheaper quarter-res, thin lines drop out).
- **glow saturation** (0–2) — 0 white-hot monochrome, 1 the HUD's own hues, 2 neon.
- **glow tint** — hue-wheel picker; multiplies the whole bloom (pale cyan = hologram cast).
- **Frost + bloom coexist** on Flat/VertexWarp. Cost: ~0.55 ms/frame CPU all-in (profiled).

### Radial glass (F10 → radial editor → "Effects (0.9.0)")
- **Frosted wedges** (needs Tier C on + Flat/VertexWarp + the bundle; shares the HUD's blur,
  so it's free when HUD frost already runs), **sheen**, and **edge light** on wedge rims.
  The section tells you why frost is inactive instead of silently doing nothing.

### Also fixed today
- Frost no longer sees THROUGH the first-person helmet (the capture includes the helmet's
  camera now).
- Inner-glow corner artifacts (X-patterns, seams, escaped flaps on the trapezoid bar) — all
  three generations of corner bugs are gone (miter respects each corner's true angle).
- Ripple spokes/rays on halos and corners (the mesh now samples the shimmer densely enough).

## Which changes need what

| You change… | Takes effect… |
|---|---|
| Any slider/toggle above | **Instantly** (bloom tint/saturation additionally need the current bundle — see below) |
| C# code | **F6** |
| Shader files (`Dev/UiaEffectsBundle/Assets/Shaders/`) | Bundle rebuild, then **game RESTART** — F6 is NOT enough for shaders: the loaded bundle stays resident in memory. (Claude rebuilds headlessly, even while the game runs — the dev bundle loads from memory since 2026-07-15, so the file is never locked.) |

## Fix-round notes (2026-07-14 play-test → fixes)

1. **Frost now works with Tier B off** (the per-element strength channel was gated on Tier B).
2. **Iridescence is rim-only and ~60% weaker** — the full-panel rainbow stripes are gone.
3. **Sheen survives frost** — the glass composite now paints the panel OVER the frosted
   backdrop instead of additively washing it out (also: the raw un-blurred world no longer
   bleeds through frosted panels).

5. **Hand boxes + 1-6 equipment boxes now receive effects** (they styled their glass by hand
   and had been skipped by the effect wiring).
6. **ImGui windows can't escape the screen anymore** (auto-clamped every frame).
7. Profiler snapshots go to the right folder.
8. *(Your finding, no fix needed:)* per-element **Warp/curve** checkboxes were off on the
   hand/equipment elements — that's the curvature toggle, working as designed.
